# SwasthyaSetu AI — Multimodal Healthcare Triage Assistant
**Problem Statement:** Multimodal Healthcare Triage Assistant for Government and Institutional Health Facilities (BPUT/STISTC Hackathon)

> **⚠️ Educational Prototype Notice:**  
> **Triage Support Only — Not for Diagnosis or Treatment.**  
> Information generated by this system is advisory and must be reviewed by a qualified healthcare professional. All patient profiles, medical registration IDs, and Aadhaar tokens are 100% synthetic demonstration data.

---

## 🌟 Overview

**SwasthyaSetu AI** (*“Smarter information. Faster review. Better-connected care.”*) is a modern, responsive web application engineered for public healthcare institutions, Primary Health Centres (PHCs), Community Health Centres (CHCs), and tertiary medical colleges.

It assists qualified healthcare workers by organizing multimodal patient-provided symptoms, voice descriptions, medical reports (via OCR), and images into structured clinical triage notes.

---

## 🏥 Three Core Interface Experiences

1. **Secure Authentication & Verification** (`/login`, `/register/patient`, `/register/doctor`, `/verify`)
   - Dual-tab login for Patient and Healthcare Worker portals with 1-click judge demo profiles.
   - 3-step patient registration with simulated Aadhaar OTP verification and informed consent ledger.
   - Medical professional registration with simulated state council license validation.
   - Trust and credential verification sandbox.

2. **Multilingual Patient Portal** (`/patient/*`)
   - Intuitive dashboard with live queue progress tracking.
   - Multimodal intake supporting conversational text, speech recording with animated audio waveform, and medical report OCR.
   - Regional language recognition (Odia, Hindi, Bengali, Tamil, etc.) with automatic translation to English for clinicians.
   - Digital Health Locker for extracted lab parameters.
   - Interactive Q&A for responding to doctor inquiries.

3. **Healthcare Worker / Doctor Portal** (`/doctor/*`)
   - High-density clinical dashboard with real-time triage metrics.
   - Priority-sorted patient queue categorized by risk signals (🔴 HIGH PRIORITY, 🟠 ATTENTION, 🟢 ROUTINE).
   - 3-column clinical review workspace:
     - **Left:** Patient demographics, verified identity, and multimodal input indicators.
     - **Center:** Multimodal tabs, structured triage note, urgency signals, follow-up questions, and AI explainability.
     - **Right:** Clinical decision-support actions (*Mark Reviewed, Request More Information, Prepare Referral Note, Add to Priority Queue*).
   - Standardized institutional referral note generator with inline editing, print/PDF export, and clipboard copy.
   - Immutable audit trail with timestamps and SHA-256 event hashes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/soumya0166-debug/mediq.git
cd mediq

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the application.
